## 2026-09 更新说明

### 交易系统 V1.1(2026-09-14)

- 修订动因:V1.0 模糊词(有效跌破/站稳/冲不动)实盘会被情绪钻空子;卖出规则最薄;加仓后风险翻倍;回测与实盘两套规则
- 核心条款:收盘价跌破无效点 → 次日开盘无条件离场(盘中跌破只记录不决策);四种客观退出(破位止损/回撤止盈/时间止损5日/破位反抽不接回);加仓三问(价位/新无效点/加仓后风险 ≤ 1%);大盘 20 日线开仓开关
- 绩效:R 统计 + 月度 5 指标(胜率/盈亏比/平均R/最大连亏/总R),月度风控阀 -5R 停一周
- 分工:实盘纪律以交易卡为准,量化回测降级为统计参考(方案 B)

### 组合回测(2026-09-14)

- 落地于历史回放页(HistoricalBacktestWorkspace),非原规划的策略回测页
- 撮合引擎 `services/selection-worker/portfolio_simulator.go`:T+1、涨停买不进/跌停卖不出顺延、100 股整手、最大持仓、等权、现金不足降级
- 费率:买入 0.05% / 卖出 0.1%(含印花税),引擎内兜底
- 交易流水落库 `historical_backtest_trades` 表 + `/api/historical-backtests/{id}/trades` 分页 API;前端交易记录 Tab + 绩效汇总条
- 退出优先级:止损(≤-8%)> 回撤止盈(+12% 激活/峰值回撤 10%)> MA20 > 40 天
- 未实施:SVG 净值曲线、月度收益表、单标的策略回测(mode=symbol)

### 实盘盘中补K(2026-09-15)

- 动机:14:45 尾盘选股 + 当日买入,次日(T+1)即可卖,比"次日开盘买入"提前一天解锁卖出权
- 三层判定:今天是否交易日(workday 接口,失败按周内日兑底)→ 最后一根 K 日期 == 今天 → 拉实时快照合成今日 K(不落库)
- 复权:adj 比值法(adj = 历史前复权昨收 / 快照真实昨收),除权日无假缺口
- 边界:仅实盘选股路径挂载(system_strategy_batch.go),回测不受影响;停牌/无快照 → 纯股票跳过,指数基准保留库内 K
- 状态:M1+M2 已实施(12 个单元测试),M3 双口径对照验证(14:45 vs 收盘)待实盘数据
