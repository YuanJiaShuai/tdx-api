## 1. 问题诊断:V1.0 的四个缺口

### 1.1 四层评审结论

| 层面 | 结论 | 明细 |
|---|---|---|
| 理念层 | ✅ 方向全对 | 风控优先、结构止损、金字塔加仓、复盘意识 |
| 规则层 | ⚠️ 模糊词过多 | "有效跌破/站稳/冲不动/不能过差"等,实盘会被情绪钻空子 |
| 结构层 | ❌ 两个断层 | ①回测规则与实盘规则脱节 ②加仓后风控缺失 ③卖出规则最薄 |
| 数据层 | ⚠️ 无绩效统计 | 复盘是问答式,没有 R 统计与月度指标,无法验证"稳定盈利" |

### 1.2 每个缺口的"实盘代价"(问题不是理论,是钱)

**缺口 A:模糊词如何被情绪利用(规则层)**

以"有效跌破"为例,实盘推演:

```
9:45  跌破 39.60,"15 分钟还没到,再观察"
10:10 跌到 39.20,"缩量,可能是假破,再等等"
11:00 拉回 39.50,"快收回了,确认是不是假破"
14:30 又跌破,"快收盘了,等收盘确认"
收盘  39.30,"明天要是低开就走"
次日  低开 39.00,"已经跌了这么多了,反弹再走吧"
```

每一步单独看都"有道理",合起来就是**止损从 -1.2 元变成 -3 元、-5 元**。规则里任何需要"感觉"确认的词,都会在亏损扩大时被情绪接管——这不是意志力问题,是规则设计问题。**唯一解:把决策权从"盘中的人"移交给"收盘价的数字"。**

**缺口 B:加仓后风险翻倍(结构层)**

V1.0 只定义了试错仓的无效点(税友 39.60),确认仓进场后打什么止损没写。若确认仓也打 39.60:

```
试错仓 300 股:风险 360 元(0.64%)——合格
确认仓 400 股:风险 400×(42.60-39.60)= 1200 元
合计风险:1560 元 ≈ 2.77% 账户
```

一次"正确的加仓"把账户风险放大 4 倍。金字塔加仓的本意是"看对了才加大",结果变成了"看对了就赌大"。

**缺口 C:卖出规则只有半句(结构层)**

整份 V1.0,买入、止损、加仓写得很细,"卖出/止盈"只有"反弹到 45-46 且冲不动,优先锁定利润"半句。短线交易中**卖出比买入更决定盈亏**:同样是 +15% 的行情,有人 +3% 就跑,有人 -5% 才走,差距在卖出规则,不在买入。

**缺口 D:回测与实盘两套规则(结构层,最根本)**

| | 量化回测(刚设计的组合回测) | 交易系统 V1.0(实盘) |
|---|---|---|
| 止损 | 固定 8% | 技术无效点(39.60,约 3%) |
| 止盈 | 12% 触发 + 回撤 10% | "45-46 冲不动" |
| 持有 | 最长 40 天 | 破位离场、站稳加仓 |

回测验证的规则 ≠ 实盘执行的规则,**回测结论对实盘没有预测意义**。修法见第 6 章分工方案。

**缺口 E:没有绩效数字(数据层)**

复盘问题产出的是"文字",不是"数据"。"这个月做得怎么样"目前只能靠感觉回答。没有胜率、盈亏比、最大连亏,就无法回答你最关心的"稳定盈利"四个字。

## 2. 修订总则与设计原理

### 2.1 三条铁律

1. **每个规则必须能被"是/否"验证**——凡需要"感觉"判断的条款,一律替换为可验证标准
2. **卖出与买入同等重要**——短线交易中卖出更决定盈亏,必须补全客观退出规则
3. **每次加仓后,账户总风险不允许变大**——金字塔加仓的精髓是"仓位变大、风险不变"

### 2.2 背后的交易原理(为什么这三条是对的)

- **R 倍数思维**:每笔交易先定义 1R(计划亏损金额),盈亏都按 R 衡量。交易系统的目标是"让平均 R > 0",而不是"每笔都赚"。
- **期望值公式**:期望 = 胜率 × 平均盈利 R - (1-胜率) × 平均亏损 R。三个变量:胜率、盈亏比、单笔风险。系统只能控制后两个(盈亏比靠卖出规则,单笔风险靠仓位)。
- **纪律 > 预测**:没人能保证下一笔对错,但规则可以保证"错的时候亏得小、对的时候赚得够"。交易系统 V1.1 的全部条款都是在保护这个不等式。

## 3. V1.1 完整条款草案(可直接替换 V1.0)

> 以下条款按建议值起草,标注 ★ 的为第 9 章待拍板决策点。

### 3.1 核心原则(修订版)

1. 先确定交易模式,再选股票。
2. 买入前写清楚买入理由、技术无效点、最大亏损和退出计划。
3. 止损以技术无效点为唯一依据,盘中跌破只记录,收盘跌破则次日开盘执行。★1
4. 轻仓试错不是问题;盈利放大依赖确认后的加仓,每次加仓必须先回答"加仓三问"(3.5 节)。★5 ★6
5. 卖出与买入同等重要,四种客观退出(3.6 节)触发即执行,不做主观"再等等"。
6. 止损后股价拉回不代表原计划错误,破位反抽不接回。
7. 大盘 20 日线是开仓总开关(3.7 节)。★7
8. 先做到亏损可控、交易不乱,再谈稳定盈利;每笔交易都要有 R 记录,每月看绩效数字(3.9 节)。

### 3.2 当前模式(修订版)

```text
强势股回调到关键支撑附近,轻仓试错,确认转强后再考虑加仓。
```

**候选股特征(量化标准)**:

- 最近 20 个交易日内出现过涨停或单日涨幅 ≥ 7% 的大阳线(排除一字板无量)
- 从阶段高点回调 15%~30%(不足 15% 说明没到支撑区,超过 30% 说明强势逻辑可能破坏)
- 回调接近以下结构位之一:起涨点、第一根涨停/大阳线低点、加速段低点、平台低点
- 买入价距技术无效点 ≤ 5%(超过则放弃,等更好的位置)
- 基本面或题材没有明显变坏(出现立案调查、业绩暴雷等,一票否决)
- 大盘 20 日线开仓开关处于"开"状态(3.7 节)

**模式适用环境**:该模式赚的是"强势股修复"的钱,在指数站上 20 日线、市场有赚钱效应时胜率最高;指数跌破 20 日线期间该模式停止开新仓。

### 3.3 无效点(止损位)定义(修订版)

**无效点 = 买入逻辑的证伪位**:价格有效跌破它,说明"回调到支撑会转强"的判断错了,无条件认错。

常见结构位(按短线优先级):

1. 加速段低点(离当前价近、结构意义强,短线首选)
2. 第一根涨停/大阳线低点(第一批强买盘的防守区)
3. 平台整理低点(确认仓加仓后的新无效点来源)
4. 起涨点(波段级别,离得远,仅中线参考)

**"有效跌破"的唯一定义(★1)**:

```
收盘价 < 无效点 → 次日开盘无条件执行减仓/离场
盘中跌破后收回 → 只记录,不决策,次日收盘再判
```

### 3.4 买入与仓位(修订版)

**买入流程**:

1. 收盘后(或开盘前)确认候选满足 3.2 全部特征
2. 填写交易卡(3.8 节):写清买入理由、无效点、计划亏损、退出计划
3. 检查单笔风险:计划亏损 / 账户总资产 ≤ 1%(★6)
4. 确认大盘开关为"开"
5. 次日开盘按计划执行(与回测引擎成交假设一致)

**仓位框架(保留 V1.0,补风险约束)**:

```text
试错仓:20%-30% 市值(单笔风险 ≤ 1% 账户)
确认仓:30%-40% 市值(加仓后合计风险 ≤ 1% 账户)
趋势仓:剩余仓位(同上约束)
```

### 3.5 加仓三问(★5 新增,最高优先级)

每次加仓前必须回答三个问题,**答不出任何一个就不加**:

1. **加仓价位**:确认信号是什么?(如"连续 2 日收盘站上 42.60 且不回破"★2)
2. **新无效点在哪**:加仓后无效点上移到哪里?(默认:最近一个确认结构低点)
3. **加仓后风险多少**:全部仓位合计,若跌破新无效点,亏损金额 / 账户总资产 ≤ 1%?

税友完整示例:

```
试错仓:300 股 @40.80,无效点 39.60,风险 360 元(0.64%)✅
加仓确认:连续 2 日收盘站上 42.60 且不回破
确认仓:400 股 @42.60
新无效点:41.50(加仓前整理平台低点下方)
加仓后合计风险:
  试错仓 40.80 → 41.50 = 浮盈,不承担亏损
  确认仓 42.60 → 41.50 = 1.10 × 400 = 440 元
  440 / 56279 ≈ 0.78% ≤ 1% ✅ 仓位变大、风险不变
```

### 3.6 卖出规则:四种客观退出(★3 ★4 修订)

| # | 退出方式 | 触发条件 | 执行方式 |
|---|---|---|---|
| 1 | 破位止损 | 收盘价 < 无效点 | 次日开盘离场 |
| 2 | 回撤止盈 | 触及目标区(45-46)后,从区间高点回撤 3% 或收盘跌破 5 日线(★3) | 次日开盘离场 |
| 3 | 时间止损 | 买入后 5 个交易日价格未创新高且未按预期走强(★4) | 次日开盘离场 |
| 4 | 破位反抽不接回 | 止损离场后,股价反抽不过原无效点 | 不接回、不补仓 |

要点:

- 四种退出**触发即执行**,不存在"再观察一天"(除非收盘价未触发)
- 回撤止盈的目的:让盈利单有空间奔跑,但绝不让 +10% 的浮盈变成亏损单
- 时间止损的目的:资金是有机会成本的,5 天不涨的强势股通常不再是强势股

### 3.7 大盘择时开关(★7 新增)

- **开仓开关**:上证指数收盘价 ≥ 20 日均线 → 允许开新仓
- **减仓开关**:上证指数收盘价 < 20 日均线 → 不开新仓,已有持仓按各自无效点正常执行
- 数据来源:本项目行情模块每日收盘后自动可取(sh000001 日线)
- 说明:这是防熊市逆势试错的粗粒度开关,不追求精确择时,只做"大环境过滤"

### 3.8 交易卡模板 v1.1

```text
股票:
买入日期:
买入价:
股数:
仓位:                  # 试错仓/确认仓/趋势仓
交易模式:              # 强势股回调支撑试错
买入理由:              # 对号 3.2 的哪几条特征
技术无效点:            # 结构位 + 具体价格
最大亏损:              # 金额 + 账户风险%(即 1R)
第一观察位:
第一压力位:
强压力位:
加仓条件:              # 加仓三问:价位/新无效点/加仓后风险%
止盈条件:              # 目标区 + 回撤幅度
时间止损:              # 买入日 + 5 个交易日
破位处理:              # 收盘跌破无效点 → 次日开盘执行
大盘开关:              # 开仓当日上证是否站上 20 日线
计划R / 实际R:          # 交易结束后填写
盘后复盘:              # 按 3.10 每日三问
```

### 3.9 R 统计与绩效汇总(新增)

**每笔交易记录**:计划 R(下单前写明的计划亏损金额)、实际 R(实际盈亏 ÷ 计划 R)。

**月度汇总(必看 5 个数)**:

| 指标 | 含义 | 健康区间(个人短线) |
|---|---|---|
| 胜率 | 盈利笔数 / 总笔数 | 40%~60% |
| 盈亏比 | 平均盈利 R / 平均亏损 R | ≥ 1.5 |
| 平均 R | 总 R / 总笔数 | > 0(核心指标) |
| 最大连亏 | 连续亏损笔数最大值 | ≤ 4 笔 |
| 总 R | 当月累计 R | 目标:+3R 以上 |

**示例(10 笔交易)**:

```
计划 R = 360 元/笔
结果:4 笔 +1.5R、2 笔 +1R、4 笔 -1R
总 R = 4×1.5 + 2×1 - 4×1 = +4R = +1440 元
胜率 60%,盈亏比 (6+2)/4 = 2.0,平均 R = 0.4
结论:系统有效(平均 R 为正),下月可继续
```

**月度风控阀(建议)**:当月累计亏损达到 -5R → 停止开新仓一周,只复盘不交易,防止连亏期报复性加码。

### 3.10 复盘流程(修订版)

**每日盘后三问(必答)**:

1. 今天有没有按交易卡执行?(有偏差必须写明原因)
2. 持仓的买入理由是否仍成立?无效点是否守住?量能是放大还是缩小?
3. 操作是按规则,还是按情绪?

**每周复盘(周末 15 分钟)**:

1. 本周每笔交易是否合规(有没有规则外操作)
2. 本周总 R、最大连亏
3. 违规操作的下次拦截方式(写在交易卡模板上)

**每月复盘(月末 30 分钟)**:

1. 月度 5 指标(3.9 节)
2. 亏损笔的共同特征(买点问题?卖点问题?大盘问题?)
3. 是否需要调整系统参数(调整必须记录理由,不因单笔结果改规则)

## 4. 税友案例完整推演(按 V1.1 规则重演)

**原始交易**:603171 税友股份,300 股 @40.80(2026-08-26),无效点 39.60,风险 360 元(0.64%)。

### 4.1 买入合规检查(按 V1.1)

| 3.2 特征 | 是否满足 | 证据 |
|---|---|---|
| 20 日内有涨停/大阳线 | ✅ | 前期 34.42 启动冲到 52.10 |
| 回调 15%~30% | ✅ | 52.10 → 40.80 约 -21.7% |
| 接近结构位 | ✅ | 加速段低点 39.60 |
| 距无效点 ≤ 5% | ✅ | (40.80-39.60)/40.80 ≈ 2.9% |
| 单笔风险 ≤ 1% | ✅ | 0.64% |
| 大盘开关 | 待查 | 2026-08-26 上证是否站上 20 日线 |

**结论:买入本身是合格的执行样本。**

### 4.2 后续各场景应对表(核心价值)

| 场景 | V1.0 原文做法 | V1.1 规定动作 |
|---|---|---|
| 盘中跌破 39.60 后收回 | "观察是否是假破" | 记录到交易卡,不决策;收盘站回 39.60 上方则继续持有 |
| 收盘 < 39.60 | "有效跌破先减仓或离场" | **次日开盘无条件离场**(全仓或减半按 3.6 规则 1) |
| 连续 2 日收盘站上 42.60 且不回破 | "站稳 42.60-43.30 再考虑确认仓" | 执行加仓三问:价位 42.60 附近 / 新无效点 41.50 / 加仓后风险 0.78% ≤ 1%,三问全过才加仓 |
| 反弹到 45-46 后回撤 3% | "冲不动优先锁定" | 触及 45-46 后,从区间高点回撤 3% 或收盘破 5 日线 → 次日开盘止盈 |
| 买入后 5 日未创新高 | 无规则 | 时间止损,次日开盘离场 |
| 大盘跌破 20 日线 | "大盘环境不能过差"(主观) | 不再开新仓;税友持仓按自身无效点执行 |
| 止损离场后反抽到 40 | "不接回,不补仓" | 保持 V1.0(已合规) |

### 4.3 推演结论

- V1.0 里"减仓还是离场""假破还是真破""冲不动是什么"这些决策,在 V1.1 里全部有了唯一答案
- 唯一留给"盘中的人"做的事:**执行**,而不是**判断**

## 5. 实盘执行手册(把系统变成日常)

### 5.1 盘前(约 15 分钟)

1. 看大盘开关:上证收盘价 vs 20 日线 → 记录"开/关"
2. 查候选池:量化选股系统每日信号 + 自选观察列表
3. 对拟买标的填交易卡草案(买入理由、无效点、1R)
4. 检查今日是否有持仓触发四种退出(3.6 节)的收盘条件(看昨日收盘)

### 5.2 盘中(纪律执行)

1. 只执行交易卡上已写明的条款:触发买入价 → 买;触发止损/止盈条件 → 卖
2. 盘中跌破无效点:**记录到交易卡,不做任何决策**
3. 一切"临时起意"的操作 = 违规,盘后必须在复盘里写明

### 5.3 盘后(约 15 分钟)

1. 更新持仓状态:收盘价 vs 无效点/目标区/时间止损天数
2. 已结束交易:填实际 R,写每日三问
3. 生成次日操作清单:哪些持仓明早要按规则执行

### 5.4 周/月

- 周五:每周复盘(3.10 节)
- 月末:月度 5 指标 + 风控阀检查(-5R 则停一周)

## 6. 与量化系统的分工定位(解决两套规则脱节)

**采纳方案 B(轻量)**:承认分工、各自闭环。

| 系统 | 定位 | 产出 | 验证方式 |
|---|---|---|---|
| 量化选股系统 | 信号池 + 研究统计 | 每日候选 + 因子信号 + 回测统计 | 组合回测、信号绩效 CSV |
| 交易系统 V1.1 | 实盘唯一纪律 + 真实绩效 | 交易卡 + R 统计 + 月度汇总 | **真实成交记录**(不回测) |

**每日衔接流程**:

```
收盘后:量化系统出信号/候选 → 对照 3.2 特征人工确认 → 填交易卡
次日开盘:按交易卡执行(与组合回测"次日开盘成交"口径一致)
盘后:更新交易卡 + R 统计
月末:交易系统月度 5 指标(真裁判);量化系统信号绩效 CSV(参考)
```

**关键声明**:

- 实盘纪律以交易卡为准,回测参数(8% 止损、40 天持有)只是研究口径,不约束实盘
- 实盘"稳定盈利"的验收 = 月度 5 指标持续健康(平均 R > 0、最大连亏 ≤ 4),不是回测年化
- 未来若做"实盘信号跟踪"(按真实买入区间跟踪信号后续表现),口径与组合回测天然对齐

## 7. 常见心理陷阱与系统兜底

| 陷阱 | 实盘表现 | V1.1 兜底条款 |
|---|---|---|
| 假破拉回就追 | "收回来了,买入理由还在,买回来" | 3.6 规则 4:破位反抽不接回 |
| 亏损加仓摊平 | "再买点摊低成本,反弹就解套" | 3.5 加仓三问:只在浮盈 + 站稳后加,摊平型加仓三问必不过 |
| 盈利单拿不住 | 小赚 3% 就跑,错过大波段 | 3.6 规则 2:回撤止盈给浮盈空间,不提前主动止盈 |
| 套牢式等待 | "迟早会回来的,不动了" | 3.6 规则 3:时间止损 5 天 |
| 连亏后报复性加码 | "前面亏了,这把要赚回来" | 3.9 月度风控阀:-5R 停一周;单笔风险始终 ≤ 1% |
| 信号来了不敢买 | "上次就是买完就跌" | 3.4 流程:交易卡写清 1R 风险,敢亏才敢买;≤1% 的风险不该犹豫 |
| 盘中冲动交易 | 临时看到消息/异动就下手 | 5.2:一切临时起意 = 违规,盘后必写原因 |
