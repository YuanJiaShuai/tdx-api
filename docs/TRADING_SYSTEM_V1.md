# 交易系统 V1

交易系统 V1 是个人交易记录和风控工具，不提供买卖建议，也不保证盈利。它的目标是把每一笔交易从“凭感觉”变成“有理由、有无效点、有最大亏损、有复盘”的可检查流程。

## 核心原则

1. 先确定交易模式，再选股票。
2. 买入前写清楚买入理由、技术无效点、最大亏损和退出计划。
3. 止损位优先使用“技术无效点”，再检查这个位置对应的亏损是否能接受。
4. 轻仓试错不是问题，盈利放大依赖确认后的加仓规则。
5. 加仓不是无脑越涨越买，而是走势证明判断正确后再增加仓位。
6. 止损后股价拉回不代表原计划错误，失控追高才容易扩大错误。
7. 先做到亏损可控、交易不乱，再谈稳定盈利。

## 当前模式

当前先训练一种模式：

```text
强势股回调到关键支撑附近，轻仓试错，确认转强后再考虑加仓。
```

适合观察的股票特征：

- 最近一段时间有明显放量上涨、涨停或大阳线。
- 从阶段高点回调约 15%-30%。
- 回调接近前期强势 K 线低点、平台支撑或加速段起点。
- 买入价距离技术无效点较近，计划亏损可控。
- 基本面或题材没有明显变坏。
- 大盘环境不能过差。

## 支撑位和无效点

支撑位不是一个神秘价格，而是上一轮买盘曾经明显用力的位置。常见观察点：

- 起涨点：整段行情最早启动的位置，适合做波段级别参考。
- 第一根涨停或大阳线低点：代表第一批强买盘的防守区域。
- 加速段低点：代表短线资金明显接力的位置，适合做短线无效点参考。
- 最近低点：用于观察当下卖压是否减弱。

短线交易更重视“离当前价最近、又有结构意义”的无效点。中线交易才会看更远的起涨点。

有效跌破通常看：

- 跌破后 15-30 分钟不能快速收回。
- 当天收盘价低于关键位。
- 跌破后反抽到原支撑区域明显受压，再次回落。
- 放量跌破比缩量跌破更危险。

## 税友股份样本

```text
股票：税友股份 603171
买入日期：2026-08-26
买入价：40.80
股数：300
持仓市值：12087.00
总资产：56279.20
本金：50000.00
仓位占比：约 21.5%
交易类型：强势股回调支撑试错
```

买入理由：

- 前期从 34.42 附近启动，最高冲到 52.10，说明曾经有明显资金推动。
- 从 8 月 6 日高点 52.10 回落到 40 元附近，短线存在修复可能。
- 当前价格接近 7 月 31 日加速段低点 39.60。
- 买入价 40.80 距离 39.60 风控位约 1.20 元，亏损比例约 2.94%，风险可控。

技术无效点：

```text
有效跌破 39.60
```

资金风险：

```text
单股风险：40.80 - 39.60 = 1.20
300 股计划亏损：1.20 * 300 = 360.00
账户计划风险：360.00 / 56279.20 = 0.64%
```

操作计划：

- 有效跌破 39.60 且收不回，先减仓或离场。
- 盘中短暂跌破 39.60 后快速拉回 40 元上方，观察是否是假破。
- 重新站稳 40.80，说明短线压力减轻。
- 站稳 42.60-43.30，说明短线企稳增强，再考虑确认仓。
- 反弹到 45-46 且冲不动，优先锁定利润。
- 跌破 39.60 后反抽不过 40 元，不接回，不补仓。

## 仓位框架

```text
试错仓：20%-30%
确认仓：30%-40%
趋势仓：剩余仓位
```

试错仓负责验证判断。看错时小亏离场，看对后再用确认仓放大利润。趋势仓只在趋势进一步确认后使用。

## 复盘问题

每笔交易结束或盘后更新时，至少回答：

- 今天有没有按计划执行？
- 买入理由是否仍然成立？
- 技术无效点是否守住？
- 成交量是放大还是缩小？
- 反弹时有没有主动买盘？
- 操作是按规则，还是按情绪？
- 下次哪里可以改进？
